# Druckwaage – interaktive Simulation Die Simulation ist eine einzelne, offline nutzbare HTML-Datei ohne externe Bibliotheken. ## Verwendung auf GitHub Pages 1. Den gesamten Inhalt dieses Ordners in einen Ordner des GitHub-Repositories hochladen. 2. Die Datei `index.html` im Browser öffnen oder über GitHub Pages aufrufen. 3. Die vier Schieberegler verändern Masse und Querschnittsfläche beider Kolben. 4. Mit „Druck einblenden“ werden die Druckwerte und die Druckpfeile angezeigt. Die Startwerte betragen (m_1=20\,\mathrm{g}), (m_2=20\,\mathrm{g}), (A_1=1{,}0\,\mathrm{cm^2}) und (A_2=2{,}0\,\mathrm{cm^2}).
